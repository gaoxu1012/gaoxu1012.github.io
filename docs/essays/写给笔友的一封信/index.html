写给笔友的一封信

在小红书刷到了一篇交笔友的帖子，兴起，写此篇，后无音讯

2026年11月7日星期六 阅读时长: 3 分钟

不知道怎么给信开头，便去请教豆包，豆包说：展信安，素昧平生，冒昧提笔。

关于慢通信

我也生长在即时通讯的时代，写一封长信变成了一种新奇事。人们习惯于用三言两语去表达，或追求语义的高效，或追求沟通的高效，总之，要快，要准，要提高沟通效率，要降低沟通成本……真无趣啊

有时候，我会想象写信是什么样的感受，贴上邮票，等待。等待时间过去，等待不确定性落地，好像小学时和朋友约定时间地点明天一起出来玩。要经历漫长的等待，不知道他是否记得，不知道他是否可以。直到见面的时候，所有的不安和失落一扫而空，都不再计较什么时间的早晚，抓起新的玩具，分享留了好久的零食，那是一种慢通信的浪漫，我不能反反复复的确认，所以我时刻保有期待。

现在是2026年，我以为笔友作为上个时代的产物，如同我儿时的玩伴一样悄然离去了。所以，很高兴认识你。

关于自我介绍

好像我需要补一个迟来的自我介绍，你可以叫我“旭”，非典型intp，06年男生大学在读，因为一些原因不知自己的生辰八字，算是不被命定之人，笑~ 。显而易见，我比较文青，不过想来会用邮件交流的人多少都带着几分文青，那我也不算太突兀。不知道别人会如何介绍自己，是会贴上大把的标签等待对方解密还是寥寥几笔有意的弱化身份，我很好奇。

关于intp

intp是一种思绪很重的生物，很像蜗牛，背着巨大的思想包袱，而且眼睛突兀的立在头顶上，将多半的目光落在自己身上，总是躲在自己的精神空间里，以便随时可以裹紧小被子。永远有自己感兴趣的东西，莫名奇妙的，intp总觉得自己莫名其妙，而且巨额知识来历不明，受击特效很丰富，所以我很喜欢我的intp朋友，不过我希望医学生的他在做手术时不会突然好奇无影灯是不是真的没有死角。

我也是intp，但是社会对intp并不友好。i人，在古代也许是君子书生，但在当代西化后中国社会中显得太过弱小且格格不入，所以我得学会梳起e人的发型。n性t性高更是无妄之灾，我们只是抽象喜欢逻辑，不是ADHD，也不是NPD，但显然工作中的员工更喜欢条理明确的s人，s人在工具理性的社会确实更有利。至于p性，好吧，我就是懒，风暴中的旅行者不在乎帽子的logal是否摆正（-_-）! 不过，为了好好生活，我还是变成了非典型的intp，其实底层框架没变，只是加了一些外附的插件，笑~

关于专业

我时常听一些财经类的播客，像是知行小酒馆、面基等等，会觉得经济学的视角是一把尖刀，能够很高效的刺破虚伪的表象，经济学的视角很适合去魅。如果你愿意，也请给我推荐一本经济学相关的书。不知道你是否喜欢这个专业，会担心就业吗？除了银行、保险和金融机构，我也并不了解还有什么对口的工作，不过我倒是觉得这个专业会接近于对人本身而非工具性的培养，对博弈，风险，周期的认知更是我们工科生极度缺乏的板块，却很大的影响着未来的决策质量。大概你不会太担心就业，从你开放的性格看，你的家庭条件应该也不错，那就好好享受大学吧。目前大三的我正面临考研的抉择，不久前看了西南政法大学秦涛老师的新生致词，深受感动。秦老师说急于上岸不如好好领悟一下水下的瑰丽世界，在年轻的时候吃点好的精神食粮。现在你应该是大二或者大一，在此，也祝愿你能留下美好的校园记忆。
